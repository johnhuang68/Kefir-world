# Amasi 南部非洲酸乳

**類別：** 自然發酵或菌種-菌種酸乳\
**傳統地區：** 南部非洲，特別是南非和辛巴威\
**替代名稱：** Maas；霍澤科； mukaka wakakora（名稱和範圍有所不同）\
**證據狀態：** 文獻支援的概況；津巴布韋和南非的程序保持獨特

## 產品定位、歷史與製作

阿瑪西是南部非洲酸乳家族，而不是單一不變的菌種。津巴布韋家庭使用未經處理的牛奶，在陶器或金屬容器中發酵長達 48 小時，在某些情況下，隨後將乳清瀝乾以獲得更濃稠的產品。南非的做法包括家庭自然發酵和接種特定嗜溫菌種的現代巴氏殺菌牛奶。 [AMA001]，[AMA002]

密切相關的地區名稱並不能證明相同的菌種祖先。應記錄每個品種的乳源、容器、排水和前批次殘留物。

## 發酵、牛奶與感官特性

|流程|來源支援條件|範圍 |
|---|---|---|
|津巴布韋家庭Amasi |環境溫度，長達 **48 小時** |生牛奶；可選的乳清排水[AMA001] |
|南非實驗設計| **18–32 °C / 4–140 小時** |故意廣泛的實驗室設計，而不是傳統的範圍[AMA002] |
|模型選擇的實驗點| **25 °C / 120 小時** 或 **32 °C / 140 小時** |測量反應的最佳化輸出；不是家庭建議[AMA002] |

產品酸而濃稠，從光滑到塊狀不等。津巴布韋的描述報告了溫和的乳酸和芳香味。酸化和乳清去除都會增加表觀厚度，因此質地不應自動歸因於 EPS。對照實驗在其選定的終點處將 pH 值從 6.64 降低至約 3.99，但該結果特定於其生乳實驗。 [AMA001]，[AMA002]

## 微生物生態和菌株證據

津巴布韋阿瑪西在 20 個表型鑑定的酵母菌種中最常見的是 *Saccharomyces cerevisiae*、*Candida lusitaniae*、*C. colliculosa* 和 *Saccharomyces dairenensis*。歷史酵母名稱和 API 鑑定需要基因組確認。該研究報告了分離株計數，但沒有保藏的菌種菌株代碼。 *Lactococcus lactis* subsp. *lactis*、*Lactiplantibacillus plantarum* 和 *Lactobacillus helveticus* 被引用為阿瑪西先前工作中的主要細菌分離株。 [AMA001]

後來的南非實驗中的擴增子定序發現了LAB豐富的群落，其中乳桿菌科最為突出。擴增子分類群的辨識是群體觀察，而不是菌種和菌株名稱。 [AMA002]

後續實驗Amasi中使用的商業菌種代碼如**CHN-22**和**TCC-4**是產品配方，而不是從傳統Amasi中分離出的生物體。此處未指定通用 Amasi 菌株 ID。

## EPS，傳代與儲存與穩定性

沒有引用的研究將純化的 EPS 和經過驗證的菌株與傳統的阿瑪西質地對應。自發性發酵和容器再利用可以推動社群發展，而明確的直接發酵菌種則可以改善製程控制。這兩種實踐都無法透過無限轉移證明穩定的菌株比。

訊息來源並未確定生的家用產品、瀝乾的產品和包裝的商業產品的儲存期限。儲存宣告需要溫度、包裝、衛生和感官/微生物終點。酵母的存在可能會產生香氣或變質，這取決於菌株和豐度；單獨檢測並不能建立理想的菌種功能。

## 區別和不確定性

阿瑪西與尚比亞 [Mabisi](mabisi.md) 重疊，但文化認同和記錄的生產變體證明單獨記錄是合理的。它不會自動成為法典酸奶，因為不需要經典的優格菌種對。與產物相關的酵母菌和實驗溫度影響的證據較強，一般 LAB 成分的證據中等，菌株解析的 EPS 和多代穩定性的證據較弱。
