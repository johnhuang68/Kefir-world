# 裡海優格

**類別：** 中溫、黏稠發酵乳；日文產品名稱\
**地理關聯：** 源自高加索的血統在日本得以維持和商業化\
**菌種生態：**乳球菌；特徵二株菌種中的醋酸菌\
**證據狀態：** 文獻支援的概況；血統和製造商範圍至關重要

## 起源和身份

Ishida 及其同事將日本菌種追溯到 1986 年從高加索爪哇村帶來的牛奶。至關重要的是，它們的 FC 和 FA 分離物是**經過在日本的長期繁殖**後獲得的，而不是直接從新鮮收集的高加索牛奶中獲得。該論文還描述了一個獨立維持的譜系，具有不同的報告細菌組成。因此，地理故事並沒有建立一個不變的祖先微生物組。 [CSY001]

「裡海優格」應與[Matsoni](matsoni.md)分開記錄。共享區域協會不證明菌種身分。同樣，商業詞「優格」不足以建立*Streptococcus thermophilus*和*Lactobacillus delbrueckii* subsp. *bulgaricus*的傳統法典優格菌種組合。 [GEN001]

## 發酵條件範圍

|背景 |溫度|時間 |證據範圍|
|---|---|---|---|
|表徵研究中的繁殖乳|室溫；沒有數字定義| **24 小時** |牛奶；方法方案，不是最佳化實驗。 [CSY001] |
| Fujicco粉狀菌種，首次活化| **25–30°C** |關於**24小時** |製造商對其自己的菌種的說明。 [CSY005] |
|相同的粉末在較低的溫度下 | **20–25°C** |大約 **24–48 小時** |初始啟用，不是一般的每日傳輸時間。 [CSY005] |
| Fujicco 牛奶到牛奶的轉移 |製造商視窗 **20–30 °C** | **6–48 小時**，取決於條件 |廣泛的指導；沒有通用的最佳或可互換的時間/溫度對。 [CSY005] |

該目錄使用 **20–30 °C**，明確標記為 **製造商特定視窗**，並區分粉末活化和後續轉移。它取代了8-24小時的不合格吃水值。原紙的室溫不得追溯轉換為測量範圍。

培養分離培養基和純化代謝物的生產是不同的實驗：肉湯培養溫度和靜止細胞氧化測定都不應該成為牛奶發酵的指導。

## 傳統血統與現代生產

繁殖使用一部分發酵乳，而不是可回收的克菲爾粒。特徵性商業菌種結合了 FC 和 FA。這確定了該製劑的成分；沒有證據表明當前所有帶有日本名稱的產品都含有相同的兩種活菌株。 [CSY001]

對於新加入物，記錄供應商、產品版本、粉末與新鮮接種物、牛奶製備、轉移編號和實際溫度。家用混合菌種、指定的雙菌株菌種和僅貼有 FC 標籤的產品需要單獨記錄，直到證明等效性。

## 牛奶和感官特徵

牛奶直接記錄在原始表徵中。其特性黏度使其有別於簡單的液體酸化牛奶。 [CSY001] Fujicco 指出，低脂或調整過的牛奶會改變濃稠度和乳清分離。 [CSY005] 這是有用的特定產品體驗，而不是山羊奶、綿羊奶和水牛奶的受控比較。

應分別測量濃稠度、凝膠硬度和感知的奶油味。厚凝膠本身並不能辨識微生物種類或量化 EPS。牛奶蛋白質、脂肪和加工資訊屬於任何黏度測量；單一形容詞無法取代流變學。

## 微生物生態和已發表的菌株名稱

以下名稱保留原始出版物的標識；現代物種名稱 *Lactococcus cremoris* 對應於歷史上稱為 *L. lactis* subsp. *cremoris* 的生物。命名法的更新並不是對每個舊分離株進行新的基因組鑑定。

|有機體/公佈名稱|直接證據|限制|
|---|---|---|
| *Lactococcus lactis* subsp. *cremoris* **FC** |表型和基於 DNA 的識別；日本菌種中兼性厭氧乳球菌。 [CSY001] |已公佈的菌株名稱，並非高加索牛奶的通用編號 |
| *Acetobacter orientalis* **FA** |需氧分離株與 FC 一起具有特徵。 [CSY001] |請勿與 KYG22 合併 |
| *A. orientalis* **KYG22** |命名為裡海優格分離物，研究用於乳糖氧化和乳糖酸生產。 [CSY002]、[CSY003] |單獨發表的分離株；此處尚未確定 FA 的身份 |
| EPS-產生 *L. lactis* subsp. *cremoris*，**此處未命名** |用於 EPS 加工實驗的商業裡海酸奶分離物。 [CSY004] |從檢查的證據來看，沒有經過驗證的產品代碼；不要將其重新命名為 FC |

透過兩種菌株的表徵，酵母和黴菌**並未被證明是必需的夥伴**。它們在選定的菌種中不存在並不能證明它們在每個家戶系譜中都不存在。此配置中未指定酵母或真菌菌株 ID。

## EPS 和黏液形成

Ohba 和同事直接研究了來自商業裡海優格的 *cremoris* 分離物中的 EPS 生產。中等脈衝電場處理改變了聚合物產率和分子尺寸；他們的分析涉及EPS生物合成和釋放。這支援依賴菌株和製程的多醣生產，而不是成品的通用 EPS 濃度。介入是一種實驗性處理方法，而不是正常的家庭步驟。 [CSY004]

在沒有化學證據的情況下，請勿將這種聚合物稱為**kefiran**。裡海優格、viili 和克菲爾的類似拉絲性並未建立相同的聚合物結構或生產菌株。

## 酸化和代謝行為

乳球菌成分提供乳酸發酵，而*A. orientalis* KYG22可以將乳糖氧化成**乳糖酸**。乳糖酸在化學上與乳酸不同；氧化實驗不得描述為乳球菌的酸化率。 [CSY002]，[CSY003]

定量核磁共振研究追蹤了裡海酸奶以及保加利亞優格和克菲爾發酵過程中的化學變化。它為特定產品的代謝軌跡提供了直接證據，但僅摘要並不能提供可轉移的最終 pH 值或完整的速率模型。此處未指定通用 pH 終點、可滴定酸度或克每小時速率。 [CSY006]

對於未來的實驗，分別測量 pH、可滴定酸度、乳糖、乳酸和乳糖酸鹽。在測試有氧伴侶的作用時記錄容器/頂部空間和菌種組成；物種的氧氣需求本身並不能指定家用容器協議。

## 傳代與儲存和穩定性

Fujicco的指南要求使用帶有頂部空間的密閉清潔容器，凝固後立即冷藏，在一週左右使用成品奶或保留的菌種，並定期更換菌種。它還描述了大約一個月的冷凍菌種儲存。這些是**製造商說明**，並非所有微生物比例或質地都保持不變的受控證據。 [CSY005]

儲存後成功重置僅表示發酵活性恢復。它不建立 FC 和 FA 的恢復、原始比率的保留或轉移的無限期穩定性。這些需要特定生物體的計數和重複批次測量。

所檢查的文獻並未建立普遍的冷凍乾燥回收率、噬菌體抗性、活菌群的耐熱性或無限數量的回種世代。將它們儲存為缺失的證據，而不是從商業粉末可用性中推斷它們。

巴西對**使用控制不良的巴氏殺菌牛奶進行裡海式自發發酵**的研究發現，儘管乳球菌佔主導地位並產生酸，但*Pseudomonas*具有持久的活性。這是有用的證據，表明僅酸化並不能確定微生物質量。它沒有顯示 *Pseudomonas* 是預期的菌種成分，也沒有描述日本 FC/FA 產品中的汙染流行情況。其 60 天觀察期並非建議的儲存期限。 [CSY007]

## 證據品質與剩餘差距

- **最有力的證據：** FC/FA的鑑定；分離物特異性 KYG22 代謝；實驗性 EPS 工作。
- **合格的流程證據：** 數位家庭溫度/時間和儲存值來自指定製造商的指南。它們故意沒有被貼上初級論文最佳標籤。
- **未解決：** 縱向群落穩定性、當代高加索與日本的直接血統比較、奶種試驗、定量家庭 pH 曲線以及酵母/真菌調查。
- **解釋：** 分離功能、EPS 產生或與長壽的歷史關聯並不能確定臨床益處。

## 另一項商業菌種操作說明

Freshly Fermented 對一包菌種與 **1 L 乳品**提供 **20–25 °C／24–48 小時**的條件；後續傳代每公升約加入一湯匙七天內的前一批產品。這是另一家供應商販售的菌種，不能證明其中含有日本文獻所表徵的歷史 FC／FA 菌株組合。其數值與 Fujicco 的啟用及傳代說明分開保存。 [FF007]
