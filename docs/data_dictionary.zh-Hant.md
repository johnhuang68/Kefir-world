# 資料字典

本檔案說明 `data/fermented_milk.csv` 的核心欄位與 Kefir World 採用的證據標準。

## 核心欄位

- `name`：產品或菌種的主要英文名稱。
- `alternate_names`：常見別名、其他拼法或地區名稱。
- `region_or_origin`：地理關聯；不一定代表已證實的單一起源地。
- `temp_min_c`：選定文獻所述發酵條件的溫度下限（°C）；須配合 `fermentation_scope` 解讀。
- `temp_max_c`：該條件的溫度上限。上下限相同時，可能代表文獻中的近似操作點，而不是精確的生理極限。
- `typical_time_h`：發酵時間。可填小時數，也可使用 `overnight`、`varies`、`not established` 等有限定語意的描述；此欄不是純數值欄位，應保留製程特定的標示。
- `starter_ecology`：菌種系統的大類，例如菌粒共生體、中溫型菌種、嗜熱型菌種、自然混合菌相或乳酸菌－酵母混合菌相。
- `main_microbes_or_features`：具代表性的微生物或微生物／質地特徵，不表示完整物種名單。
- `propagation_type`：常見延續方式，例如菌粒、回種或明確組成的商業菌種。
- `notes`：重要技術背景。
- `evidence_status`：目前的信心水準或驗證狀態。
- `profile_path`：儲存庫內的 Markdown profile 路徑；若本輪審查未附連結則留空。
- `reference_ids`：以分號分隔、指向 `data/references.csv` 的外部索引鍵。這些來源連結整份 profile，不代表每一篇來源都支援該列的每一個欄位。
- `fermentation_scope`：解讀已審查數值製程欄位時的必要說明，包括來源型別、相互配對的溫度／時間條件、近似操作點與排除的情境。

前十一欄沿用最初的目錄，後三欄為新增欄位；假設欄位數固定的資料使用者必須改用新版表頭。尚未審查資料列中的空白追溯欄位表示「尚未附上」，不表示沒有相關文獻。

## 證據層級

建議後續使用以下狀態：

1. `primary-source verified` — 同行評審的原始研究直接提供相關發酵條件或微生物分析。
2. `review verified` — 高品質綜述提供支援。
3. `authoritative reference` — FAO、Codex、政府、大學或公認技術標準提供支援。
4. `traditional-source supported` — 有可信紀錄，但產品因地區或家戶做法而有明顯差異。
5. `working draft` — 合理的結構化條目，仍待正式附上來源。

截至 2026-09-08，全部 46 列使用 `literature-backed; claim-specific scope`。這是含引用與明確限制的綜合狀態，不表示每個欄位都由原始研究直接驗證。來源品質應依連結 profile 中的個別主張判斷；權威標準可以確立產品定義，但不一定能支援歷史起源或特定菌株表型。

## 參考文獻登入表

`data/references.csv` 保留原本七個欄位：

- `reference_id`：唯一且穩定的識別碼。既有 `MK` 程式碼保留；新產品使用各自字首，共用來源使用 `GEN`。同一來源跨 profile 共用一個程式碼。
- `topic`：產品／主題代稱；多個主題以分號分隔。
- `title`：可追溯的論文或機構檔案題名。
- `year`：出版年；無日期時留空。標準檔案保留最初年份，修訂範圍寫在題名中。線上先行出版與正式卷期年份的差異在 profile 書目中說明。
- `source`：期刊、出版社或發布機構。
- `url`：DOI、PubMed／PMC、出版社或機構網址。Crossref 未收錄的 DOI 仍可能有效，例如 J-STAGE／JaLC 紀錄。
- `evidence_use`：可支援的主張範圍、研究型別，以及取得全文或解讀資料時的限制。

完整作者資訊、相關章節／表格及替代全文連結位於各 profile。只有摘要可讀的來源，只能支援摘要或已查閱摘錄中實際出現的資訊。不得用網頁擷取日期推測出版年份。

## 廠商製程觀察

`data/manufacturer_processes.csv` 把具名商業菌種的操作說明與核心產品目錄分開保存。若同一來源的啟用、日常發酵、冷藏發酵、回種或發酵後瀝乳清條件不同，會建立多筆資料列。

- `observation_id`：唯一且穩定的觀察編號。
- `product`：用於連結與人工審查的產品名稱；尚未符合核心目錄條件的候選產品也可先出現在這裡。
- `source_id`：指向 `data/references.csv` 的外部索引鍵。
- `starter_form`：接種物的形式與狀態，例如新鮮菌粒、冷凍乾燥菌粒或前一批成品。
- `stage`：該資料列描述的製程階段。
- `milk_or_substrate`：來源明確寫出的乳品、鮮奶油或混合物。
- `batch_volume_ml`：來源提供的操作容量（mL）；未提供則留空。
- `inoculum`：保留來源文字或標準化用量，不推算活菌數。
- `temp_min_c`、`temp_max_c`：只有來源提供數字時才填入；單一設定點會同時填入兩欄。
- `temperature_qualifier`：如室溫、建議範圍或冰箱設定點等解讀背景。
- `time_min_h`、`time_max_h`：來源提供的時間數值範圍（小時）；該階段未單獨量化時留空。
- `time_qualifier`：影響解讀的終點、首批例外或完整復甦期。
- `endpoint_aftercare_and_scope`：可觀察終點、冷藏／瀝乳清步驟與證據限制。

除非另有獨立的產品層級證據，這些觀察不會改寫核心目錄的 `temp_min_c`、`temp_max_c` 或 `typical_time_h`。供應商使用的產品名稱無法證明微生物身分、菌株來源、傳統性、永久穩定回種能力或健康效益。

## 重要解讀規則

### 溫度

除非來源明確指定，否則不應為產品設定單一精確溫度。優先採用具代表性的實用範圍；不同菌種系譜採用不同條件時，應分別保留。

不要把最低與最高溫度欄位視為已實驗驗證的連續操作範圍。例如 Dahi 的 22 °C／12–14 h 與 37 °C／5–8 h 是兩套獨立製程。Långfil 約 18 °C 的操作點在本輪審查中沒有可驗證的時間。缺少時間不等於零小時。微生物實驗室生長、EPS 萃取或工業生物轉化條件，不得代替乳品發酵條件。

### 微生物生態

傳統發酵乳是動態的微生物群落。單一研究中的一株分離株，不應描述成整個產品類別的通用組成。

應區分：培養取得的活分離株、標記基因檢出、相對序列豐度與基因組層級鑑定。沒有檢出真菌或缺少真菌資料，不能證明每一批產品都不含真菌。混合多種產品後所得的研究結果，也不能在缺少樣本層級證據時歸入其中一種產品。

### 分類學名稱與識別碼

適當時應同時保留原論文名稱與現行命名。例如歷史名稱 *Lactococcus lactis* subsp. *cremoris* 是 *Lactococcus cremoris* 的同物異名，參見 2026-09-06 查閱的 [LPSN（GEN002）](https://lpsn.dsmz.de/species/lactococcus-cremoris)。分類命名更新並不等於重新鑑定過去以表型方法分類的分離株。

以下專案必須分開記錄：

| 鑑定層級 | 例子 | 意義 |
|---|---|---|
| 物種／亞種 | *L. delbrueckii* subsp. *bulgaricus* | 分類群，不是唯一菌株 |
| 已發表的分離株／菌株程式碼 | FC；LAPT 3001 | 論文特定識別碼；不能自行假定已存入菌種保藏中心 |
| 序列登入號 | CP000156 | 一筆序列紀錄，不是另一株菌 |
| 混合物／批次程式碼 | Matsoni B.1 | 多種微生物的組合，不是單一分離株 |
| 化學分餾物 | Filmjölk CNP1／CNP2 | 純化物質，不是細菌 |

不得創造菌株程式碼、把對照菌株當成產品分離株，或默默合併相似拼法。後續重新鑑定必須明確呈現：Matsoni st265 在 MAT004 中被報告為 *S. thermophilus*，MAT005 則重新鑑定為 *E. faecium*。profile 保留此歷史，不把早期鑑定當成目前結論。

### EPS、酸化與儲存

應區分肉眼觀察到的黏稠拉絲、實測 EPS 產量、多醣化學組成與基因簇潛力。細胞壁多醣不一定是分泌到乳中的增稠物；也不得把 kefiran 當成所有微生物 EPS 的通稱。

pH 觀測值、單位時間的 pH 變化、可滴定酸度與有機酸濃度是不同變數。若標為「酸化速率」的表格只提供第 3 與第 6 小時的 pH，本資料庫仍把它記為終點觀測值。

儲存資料必須保留乳種、菌種、包裝、溫度、時間與結果。感官儲存期限、活菌存活率與重新作為接種源的復甦能力不能互相替代。製造商說明須標示產品與查閱日期，不能推廣為所有家戶菌種系譜的通用表現。

### 起源

許多發酵乳具有跨越現代國界的悠久歷史。無法證明單一起源國時，應使用「與……相關」、「……地區的傳統產品」或區域名稱。

### 優格與發酵乳

本儲存庫並非每一項產品都符合 Codex 對優格的狹義定義。Kefir、Viili、Kumis、Dadih、Amasi 等多種產品，以較廣義的「發酵乳」分類更準確。

### 衍生產品

希臘優格與 Labneh 的主要特徵是發酵後濃縮／瀝乳清，不應自動視為獨立的菌種生態系統。
